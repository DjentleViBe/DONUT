# DONUT : Design and Optimization of Non-axisymmetric Unified Tori
**DONUT** (Design and Optimization of Non-axisymmetric Unified Tori) is a computational geometry tool for stellarator-type fusion reactors. It generates toroidal, non-axisymmetric plasma surfaces and coil geometries, enabling researchers to design and optimize complex 3D magnetic confinement systems.

Key features include:
- High-fidelity toroidal mesh generation
- Twist optimization for magnetic surfaces
- Compatibility with stellarator design codes and simulation workflows
- Support for 3D visualization and CAD export

**DONUT** is designed to accelerate stellarator geometry optimisation, providing a flexible framework for exploring advanced magnetic confinement configurations.

## Installation
1. Clone the repo
```
git clone https://github.com/djentlevibe/DONUT.git
```
2. Install requirements
```
pip install -r requirements.txt
```
3. Run
```
python main.py
```
